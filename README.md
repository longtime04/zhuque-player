## 它解决什么问题

Wallpaper Engine 安卓版有个让人头疼的设定：你下载的视频壁纸只存在 App 自己的地盘里，**没有提供把原视频导出来的功能**。壁纸一旦从创意工坊下架、或者你换手机、清数据，那份壁纸可能就永远找不回来了——明明它就躺在你的手机里。

朱雀解析的做法是：解析 WE 的壁纸分享包（`.mpkg`），把里面的原始视频**一帧不改、无损**地提取出来（已用 231MB 的真实壁纸包实测验证，导出文件与原视频逐字节一致）。导出之后，它本身还是一个完整的播放器 + 万能解包工具，导出的壁纸当场就能看。

## 核心功能

### 🎬 Wallpaper Engine 壁纸无损导出
- 精确解析 `.mpkg` 壁纸包，还原其中的视频、图片等原始文件
- 无损 = 不转码、不压缩，导出的就是作者上传的那一份

### 📦 万能解包
- 常规格式全支持：zip / tar / gz / bz2 / xz / 7z / jar 等
- **深度扫描**：文件改了后缀、套了壳、格式认不出来？按文件头特征把藏在里面的视频/音频/图片「雕刻」出来（支持 ftyp、RIFF、EBML、FLV、PNG、JPEG、GIF 等）
- 配套的命令行小工具 `mpkg_extract.py` 也在仓库里，电脑上也能拆 mpkg

### ▶️ 播放器
- 走系统解码器，mp4 / webm / mov 等常见格式流畅播放
- 显示模式：竖屏完整显示、横屏填充铺满，可手动锁定横/竖屏
- 暂停键两侧点按快退/快进 5 秒（长按切上一个/下一个），单曲循环、静音齐全
- 视频可设为**动态壁纸**（安卓），图片可设为桌面壁纸

### 🈯 字幕全家桶（本软件的另一大招）
- **自动加载**：视频同目录放同名 `.srt` / `.vtt` / `.ass` 字幕，打开视频自动挂上（UTF-8 / GBK 编码都能认）
- **在线翻译**：外文字幕一键翻成中文
- **四档切换**：点 CC 按钮循环切换 —— 关 → 原文 → **只看中文** → **中英双语**
- **字幕设置**：长按 CC 打开设置，可改字幕颜色（7 色）
- **语音生成字幕**：视频压根没字幕？用内置的 Whisper 语音识别（离线运行）在本机直接听写生成字幕，按语音停顿自动断句对时轴；生成的字幕会存到视频同目录，下次自动加载

### 🖼️ 图片查看
- 常见图片格式浏览，可直接设为桌面/锁屏壁纸

### 💻 Windows 版
- 同一套功能的桌面版：媒体库、万能导入、播放器、字幕翻译一应俱全
- 注意：Windows 版只能把**图片**设为壁纸（系统没有视频壁纸的位置），视频可正常播放和导出

## 使用教程

### 一、导出 Wallpaper Engine 手机版壁纸（主用法）
1. 打开 Wallpaper Engine 安卓版，**长按**你想备份的那张壁纸，点「分享」
2. 分享目标选择 **朱雀解析**（或先把 `.mpkg` 文件存下来，再打开朱雀解析用「导入文件」选它）
3. 解析完成后，里面的视频会出现在朱雀解析的媒体库里，点开就能播放
4. 把导出的视频通过文件管理/分享拷到电脑或网盘，就算完成备份了

> ⚠️ 提醒：导出备份完成前，**不要清理 WE 的 App 数据、不要删手机里的原壁纸**——那是你唯一的副本。

### 二、字幕怎么用
- 播放时点 **CC** 按钮：关 → 原文 → 只看中文 → 双语，循环切换
- **长按 CC**：打开「字幕设置」，可换显示方式和字幕颜色
- 视频没有同名字幕时，点 CC 选择「语音生成字幕」：
  1. 第一次用需要先点 **「⬇ 下载语言模型」** 大按钮（约 160MB，下一次就行）
  2. 下载完成后按钮会变成「开始生成字幕」，点它，稍等片刻即可
  3. 生成的字幕自动保存，下次打开同一视频直接就有
- 选「只看中文」时会自动在线翻译；没网或翻译失败会自动退回显示原文，不会让你没字幕看

### 三、万能导入（解包）
- 首页点「导入文件」，选任何压缩包或奇葩后缀的文件
- 能按格式解的直接解；认不出格式的会自动走深度扫描，把里面的音视频和图片找出来

### 四、设壁纸
- 图片：打开图片 → 设为壁纸
- 视频（仅安卓版）：播放页 → 设为动态壁纸

## 兼容性与边界（说实话，不吹）

- 播放走系统解码器：mp4 / webm / mov 没问题；mkv / avi 等格式能否播取决于你的手机系统自带解码能力
- **scene 类壁纸拆不出视频**：那类壁纸本质是一个程序，里面根本没有视频文件，这是原理限制，不是软件偷懒
- 真正加密（DRM）的内容无解；朱雀解析处理的是「公开容器 + 封装/混淆」这类情况
- 语音生成字幕的断句时间轴按语音停顿切分，是实用方案，不是逐字时间戳，个别断句可能不完美

## 从源码构建

无 Gradle，手工流水线（见 `build.sh`），需要：

- JDK 21、Android SDK（platforms;android-34、build-tools;36.0.0）、kotlinc
- 依赖库（放到 `libs/`）：Apache Commons Compress 1.26.2、Commons IO 2.16.1、XZ for Java 1.9（Maven Central 可下）
- 语音识别：sherpa-onnx 1.13.8 官方 AAR —— 其中 `classes.jar` 已随仓库放在 `asr/`；还需把 AAR 里 `jni/arm64-v8a/` 的 `libsherpa-onnx-jni.so` 与 `libonnxruntime.so` 放到 `asr/aar/jni/arm64-v8a/`
- 签名：`build.sh` 首次运行会生成一个自用 keystore（口令可用环境变量 `KS_PASS` 覆盖）；请勿把你自己的 keystore 提交进任何公开仓库
